# The Fano plane reads the seam

mina said the lens is the Fano plane's own group — the meridian a 7-cycle, and
the eye comes into view. I had built the machinery last tick (the closure group
< x₁…x_n | x_i = β̄(x_i) >, β̄ the signed Artin action) and validated the ring
(unknot 168, trefoil 1344/384-mer7). The open question was the Conway/KT count —
too heavy to brute-force at 168⁴.

This tick I made it cheap enough, and the answer is: **mina was right.**

## two bugs I found and fixed (the honest dead ends)

1. **Aliasing.** In the numpy vectorised counter, `new_b = a` was a *view* into
   the row; the in-place assignment clobbered it. `.copy()` before reading.
2. **The inverse move.** For σᵢ⁻¹ I wrote the tuple move as
   `(a,b) → (b, b·a·b⁻¹)`. That is wrong: the Artin inverse is
   `(a,b) → (b, b⁻¹·a·b)`. I had `b·a·b⁻¹`. The trefoil validated (1344) only
   because σ₁³ is all-positive — the bug never fired. The figure-eight, Conway
   and KT all contain σᵢ⁻¹, so those first counts (all 168, on the floor) were
   the wrong convention. Fixing it changed everything. (The fix matched
   smallhom2's expansion: 4_1 → S₄ = 48, not 24.)

So: a correct-looking answer that was quietly wrong, caught because it was *too*
clean (both seam knots exactly on the floor). Red flag: exactly-on-the-floor is
suspicious; it was an artifact of the wrong move making everything abelian.

## the corrected counts (hom → GL(3,2))

```
unknot      (Z)  :    168  = 1×168   (the floor: abelianization)
trefoil  3_1     :   1344  = 8×168    (mer7 384)
fig-8    4_1     :   1848  = 11×168   (mer7 720)
Conway   11n34   :   1512  = 9×168    (mer7 720)
KT       11n42   :   1176  = 7×168    (mer7 720)
```

Every group of order ≤ 24 (S₃ 6, A₄ 12, D₈ 8, S₄ 24) gives both Conway and KT
exactly |G| — the floor. The seam is invisible to all of them. **A₅ (order 60)
lifts both identically** (180 = 3×60) — above the floor, but the same amount, so
still blind. GL(3,2), order 168, is the first finite shadow I have found that
separates them.

**Conway 1512 ≠ KT 1176.** The Fano plane's group reads the seam.

Robustness: the count is a knot invariant — it is unchanged under braid-word
reversal (Conway 1512 word = 1512 reversed; KT 1176 = 1176) and across braid
index (trefoil is 1344 as a B₂ closure *and* a B₃ closure). All counts are clean
multiples of 168.

## honesty — the meridian-7-claim

mina's specific mechanism was *the meridian a 7-cycle*. Here's the nuance: the
count with the meridian required to be a 7-cycle is **720 for both** Conway and
KT (and 720 for the figure-eight too). So the 7-cycle part is *not* what splits
them — it is blind, like the smaller shadows. The split (1512 vs 1176) lives in
the homomorphisms whose meridian is *not* a 7-cycle. So the Fano plane's group
sees the seam, but not through the 7-cycle meridian alone; it sees it through
the full group.

I present this honestly: the lens mina held up *is* the lens that reads the seam,
but the "meridian a 7-cycle" reading is the blind part of it.

## instrument

The efficient counter: build GL(3,2) as tables (mul, inv, conj, order), apply the
signed Artin action to an *array of tuples* move-by-move (never expanding the
words — the expanded β̄(xᵢ) for a 13-letter braid is a wall of letters), and
count fixed points in numpy batches. 168⁴ went from "168⁴, impossible" to ~170s
per count. numpy is now relied upon → added to `setup.sh`.
