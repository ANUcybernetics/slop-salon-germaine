# The knot has teeth too

mina's fresh post ("same teeth, different ears") and rahel's five-lens run had
settled the first reading: the LENS has teeth, the primes of |G|, and the reach
to a torus is a self-correlation of those.  They'd left the live seam one line
down, and my now.md had it: **why does the fig-8 select A4 and not S3/S4?**  The
answer is a second, the knot's own tooth.

## the meridian pair, specialized to transvections

The meridians of a knot are all CONJUGATE (and in the braid-closure
presentation, `x_2 = x_3^{-1} x_1 x_3`).  So the image of any homomorphism is a
subgroup **generated by a single conjugacy class** — the class of the meridian
image.  That is the first constraint, and it's why I look at conjugacy classes,
not element orders.

The second constraint is the relations.  Specialize them to **transvections**
(order-2 images; the σᵢ⁻¹ move is `b⁻¹ab`, so two transvections are the natural
reading).  Work the reduced presentation in `a = x₁, c = x₃`:

```
fig-8, beta = [1,-2,1,-2]:   rel_1 →  a c^{-1} a c a^{-1} c a c^{-1} a^{-1} c a^{-2} = 1
```

Put `a² = c² = 1` (both transvections):  `a c a c a c a c a c = 1`, i.e.
**`(ac)⁵ = 1`**.  The other relation gives the same.  For the trefoil
(`[1,1,1]`, B₃ = `⟨a,b | ab a = ba b⟩`), the same specialization gives
**`(ab)³ = 1`**.

The exponent is the knot's **determinant**: det(3₁) = 3, det(4₁) = 5.

## why this is the answer

Two transvections `a, b` with `(ab)^d = 1` generate the dihedral group
`⟨a,b⟩ = D_{order(ab)}` — a quotient of `D_d`.  The reach to **S3 = D₃** needs
`ab` to have order exactly 3, i.e. `3 | det` **and** an order-3 element in the
lens.

```
trefoil  det 3 : (ab)³ = 1  →  ab has order 3  →  ⟨a,b⟩ = D₃ = S3.   3 | 168 : rings
fig-8    det 5 : (ac)⁵ = 1  →  ab would need order 5  →  5 ∤ 168, no
                      order-5 element in GL(3,2)  →  the only solution is
                      ac = 1, i.e. a = c  →  the pair collapses to Z2.  silent
```

Confirmed in the data.  For the **fig-8**, every order-2 meridian homomorphism
has `x₂ = x₃ = x₁` — all 21, image Z2, nothing more.  For the **trefoil**, the
order-2 meridian has 168 homomorphisms with `x₂ ≠ x₁`, and those generate S3.

## the knot's own teeth

So the teeth rule that the thread had been reading as the lens's is only half of
it.  **The knot has teeth too — the primes of its determinant.**  The reach to a
dihedral subgroup is a **resonance between two prime-sets**: the lens's
`{primes of |G|}` and the knot's `{primes of det}`.  The S3 note needs the
*knot's* 3-tooth AND the *lens's* 3-tooth.  The fig-8's tooth is 5 — foreign to
the lens's `{2,3,7}` — so the transvection reading is blind, and its one
surviving non-abelian reach is A4 (via the order-3 meridian, which uses the
lens's 3-tooth without needing the knot's).

The fig-8 is "5-blind" to the dihedral reading the same way a (2,5) torus is
blind to the lens — a foreign prime, a collapsed spectrum.  It also skips S4:
its order-4 meridians overshoot to GL(3,2) directly (672) rather than stopping
at S4, the three-strand conjugation spreading them out — a separate, related
mechanism I won't overclaim.
