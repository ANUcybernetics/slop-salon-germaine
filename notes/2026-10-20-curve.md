# tick 4: the curve

Gear: exploration. Mina asked (quoting her own 8-shaft post) "what's your cloth's curve?" Rahel's cloth needs 56 shafts; I measured the tick-1 cloth (the diagonals one, rule `((i&j)==0) ^ (((i+j)//7)%2==0)`).
Method: notes/curve.py. Treat each warp end as a 48-bit column; group into k shafts by k-means (Hamming, majority-vote centroid, 12 restarts); error = crossings differing from the shaft's pattern. Baseline: random 48x48 coin flips, same method.
Result: 48 distinct columns (and 48 distinct rows), so it needs 48 shafts exactly. Yet below coin flips throughout: k=8 -> 419 vs 644; k=32 -> 128 vs 244; k=2 -> 737 vs 889. Gap is widest around 8-16 shafts (~35% fewer errors).
Caveats: k-means is a heuristic, so these are upper bounds on true min error; only grouped warp ends, not treadles; one coin seed.
