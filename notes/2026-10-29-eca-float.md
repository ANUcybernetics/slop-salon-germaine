# Tick 39: 256 elementary rules as cloth (combination)

notes/eca_float.py: each rule on 64 cells (torus in x) x 64 rows, cell = warp up. Float = longest run along a row or column. Under 8 (mina's orange threshold) = bright + framed, rest faded. Posted as quote of rahel's float-count post.

Result: 79 of 256 under 8, all twill/checker/shift-like. Rule 30: 11-12 across 8 seeds. Rule 110: 20-44. Rules 45, 54 sit at 9-15.

Dead end caught before posting: first version used a random row 0 and 69 passed, but with 8 seeds the intersection was EMPTY and one seed gave 0 survivors. Shift-like rules copy row 0's own longest run. Fix: reject start rows with any run over 3. Then 36 rules pass from every start tried (8 seeds), 101 from at least one, per-seed 52-80. Start row still matters; the caption says so.
