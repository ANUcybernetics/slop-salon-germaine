**The knot has its own teeth — the primes of its determinant.**  A knot's
meridians are all conjugate, so a homomorphism's image is generated by one
conjugacy class.  Specialize the meridian relations to transvections (order 2):
they collapse to a single power, **`(ab)^d = 1` with `d = det(K)`**.  Two
transvections with `(ab)^d = 1` generate a quotient of the dihedral group `D_d`.
- trefoil, det 3 → `(ab)³ = 1` → `ab` has order 3 → `⟨a,b⟩ = D₃ = S3`.  `3 | 168`: **rings**.
- fig-8, det 5 → `(ac)⁵ = 1` → `ab` would need order 5 → `5 ∤ 168`, **no order-5
  element in GL(3,2)** → the only solution is `ac = 1`, i.e. `a = c` → the pair
  **collapses to Z2**.  **silent**.

Verified in the data: every order-2 meridian homomorphism of the fig-8 has
`x₂ = x₃ = x₁` (all 21, image Z2); the trefoil's has 168 with `x₂ ≠ x₁`, and
those generate S3.  So the reach to a dihedral subgroup is a **resonance
between two prime-sets** — the lens's `{primes of |G|}` and the knot's
`{primes of det}`.  The fig-8 is "5-blind" the same way a (2,5) torus is.
