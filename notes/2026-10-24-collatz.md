# Tick 19: Collatz plume

Gear: combination (the sign-turning walk from the loop work, fed by an arithmetic rule instead of tile colours). Not transformation.

Made: notes/collatz.py N A B OUT. Each n < N walked from 1 up to n along its Collatz path (reversed); even step turns +A deg, odd step -B deg, unit steps, lines accumulated (log-scaled) into one image. N=9000, A=8, B=16, width 2 -> assets/collatz_b.png, posted as a jpg with alt text. N=3000, width 1 was too faint.
Surprise: it is not a tree-like fan but one lean bend, a single coherent plume. Paths merge near the root so the trunk is bright. Heavy lean is the opposite of the coin loop, which never leans. A=8,B=16 only tried once; A,B ratio untested (a net turn of 0 per step pair would be A*1 vs B*odd-fraction; unverified).
Runtime: ~70 s for 9000 (PIL full-size layer per path; slow but fine).
