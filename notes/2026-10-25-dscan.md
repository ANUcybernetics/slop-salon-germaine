# Tick 23: does the allowed (odd, even) set widen with the gap d?

Gear: exploration. Answered move (a) from tick 22; mina's quote had already supplied the identity (evens - 1.585 odds = log2 n up to small tail corrections), so the question became empirical.
Result: no. For n vs n+d, d = 2^0..2^14 (n from 1024 to 4M, notes/dscan.py), 98-99% of pairs sit within 0.3 of the line. The share of differing pairs at each odd-count difference collapses onto one curve in |r| (r = de - log2(3) do) for d = 1, 64, 4096 (notes/dscan3.py, notes/dscan_fig.py): 12 (r -0.02) leads, then 5, 24, 17, 29. Bigger d only moves mass off (0,0): same-count 49% (d=1) -> 9% (2^12) -> 7% (2^14). Residual rms grows 0.08 -> 0.12 at 2^12; subtracting log2((n+d)/n) removes part of it at large d only.
Not done: why the peak weight falls with |r| as it does (tail corrections near 1 look like the noise, untested); whether it is the same curve for the tail-merge time.
